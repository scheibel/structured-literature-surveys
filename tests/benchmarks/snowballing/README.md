# Live pilot and benchmark template

The three seed papers were copied from the repository's existing DBLP temporal-treemap run. They provide a small runnable connectivity pilot. Metadata is explicitly unverified and expected_edges.csv has no asserted ground truth. Under the 2026-09-12 scope decision, citation-source quality is an accepted, reported limitation: reviewed expectations, sample judgments, and calibrated thresholds are not required work. The existing evaluator's `inconclusive` result is expected and does not by itself block component acceptance.

See [the snowballing guide](../../../docs/snowballing.md#reference-quality-smoke-tests) for execution commands and reporting semantics. Benchmark/sample review remains optional if scope changes later. No synthetic fixture DOI belongs in this directory.
